# 🧑‍💻 Nicolás Corera — Portfolio Personal

Sitio web de portfolio personal de **Nicolás Corera**, desarrollador Full Stack Jr. y estudiante de Licenciatura en Sistemas en la Universidad Torcuato Di Tella (UTDT), Argentina.

---

## 🖥️ Vista previa

El sitio presenta un diseño oscuro y minimalista con paleta de color violeta/púrpura, animaciones GSAP y una experiencia visual de alto impacto.

---

## 📁 Estructura

```
portfolio/
└── index.html       # Archivo principal (HTML + CSS + JS todo-en-uno)
```

El proyecto es un único archivo `index.html` que incluye todo el CSS embebido en `<style>` y todo el JavaScript al final del `<body>`.

---

## ✨ Características

- **Cursor personalizado** con punto y anillo animado (solo en desktop con mouse fino)
- **Navbar flotante** con efecto glassmorphism y menú hamburguesa responsive
- **Sección Hero** con layout de 2 columnas: texto a la izquierda y panel visual animado a la derecha con chips flotantes (JS, Firebase, HTML/CSS, Node.js, Git, React)
- **Sección Sobre mí** con texto descriptivo y cards de estadísticas
- **Stack Tecnológico** con tags animados al hacer scroll
- **Proyectos Destacados** en grilla de cards
- **Sección de Contacto** con links a redes sociales y modal de formulario de contacto
- **Animaciones GSAP** con ScrollTrigger en todas las secciones
- **Active nav link** dinámico según sección visible (IntersectionObserver)
- **Ruido de fondo** sutil via SVG inline

---

## 🛠️ Tecnologías usadas

| Tecnología                                     | Uso                                    |
| ---------------------------------------------- | -------------------------------------- |
| HTML5 & CSS3                                   | Estructura y estilos                   |
| JavaScript (Vanilla)                           | Interactividad y lógica                |
| [GSAP 3.12](https://gsap.com/) + ScrollTrigger | Animaciones de entrada y scroll        |
| [Font Awesome 6.4](https://fontawesome.com/)   | Iconografía                            |
| Google Fonts                                   | Tipografías: _Space Grotesk_ y _Inter_ |

> No requiere frameworks ni bundlers. Se ejecuta directamente en el navegador.

---

## 🚀 Uso

1. Clonar o descargar el repositorio.
2. Abrir `index.html` directamente en el navegador.

```bash
# Opcionalmente, con un servidor local:
npx serve .
# o
python -m http.server 8080
```
